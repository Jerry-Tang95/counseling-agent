# 安全设计与危机流程

## 1. 风险分级

| 级别 | 表现 | 处理 |
|---|---|---|
| L0 | 无风险 | 正常咨询流程 |
| L1 | 被动消极意念；家暴/性侵披露；幻觉/被控制；未成年人；诊断/药物请求 | 安全计划 / 转介 / 阻断；降低探索强度 |
| L2 | 主动自杀意念、计划/准备/手段、近期自伤；明确伤人意图 | 立即危机流程，不使用普通咨询回复 |
| L3 | 正在自伤/自杀/伤人；立即危险 | 立即引导 110/120，保持陪伴，记录事件 |

## 2. 实现顺序

```
用户消息
  ↓
risk-rules.ts（确定性规则引擎）
  ↓
L2/L3 → 固定危机回应 + 资源卡（不调用 CounselorAgent）
L1    → 安全提示 + 转介/安全计划；必要时继续对话
L0    → 正常 CounselorAgent
```

规则引擎位于 `lib/safety/risk-rules.ts`。它优先识别明确的自杀、自伤、伤人、家暴、性侵、精神病性症状、未成年人与医疗请求；宁可略微保守，也不漏掉明确高风险表达。

## 3. 安全回复原则

- 直接问：“你现在有伤害自己的打算吗？有具体计划吗？”
- 不评判、不惊慌、不甩链接；
- 不承诺保密；
- 鼓励联系信任的人、拨打 110/120/12356、前往急诊；
- 在确认安全或连接真人帮助前，保持陪伴；
- 危机事件写入 `RiskEvent`，不记录不必要的原文。

## 4. 未成年人

- 产品仅限 18 岁以上；
- 年龄门 + 文本识别（年龄、初中/小学/高中生表达）；
- 识别到未成年人：停止咨询式对话，引导监护人、学校心理老师、12356；紧急情况 110/120。

## 5. 医疗边界

- 不诊断、不评估量表、不推荐药物/剂量/停药；
- 对诊断/药物请求：明确说明 AI 边界，建议精神科/心理科，可帮助整理要问医生的问题；
- 不宣称“治愈/疗效/包好”。

## 6. 测试

- `tests/safety/cases.json`：51 条合成用例，覆盖 L0–L3、未成年人、医疗请求、边界场景；
- `corepack pnpm test:safety`：规则引擎回归，L2/L3 漏报一票否决；
- 任何触及 prompt、安全、危机流程的改动都必须重跑安全测试。

## 7. 上线前必须完成

1. 持证心理咨询师/精神科医师内容与危机流程审阅；
2. 隐私政策、用户协议法律审阅；
3. 适用的算法备案/生成式 AI 服务登记/安全评估；
4. 真实危机事件的人工升级与值班机制；
5. 数据保留与删除定时任务的实际实现与审计。
